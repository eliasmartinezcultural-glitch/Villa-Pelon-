# INVESTIGACIÓN HISTÓRICA

Villa Pelón no presentará como hecho histórico aquello que no pueda documentarse.

Para cada elemento histórico se registrará: título, fecha/período, lugar, tipo de fuente, autor/institución, archivo/colección, referencia o enlace, derechos de uso cuando corresponda, texto educativo y nivel de certeza.

Materiales previstos: fotografías, documentos, mapas, prensa histórica, testimonios, registros institucionales, libros y publicaciones.
