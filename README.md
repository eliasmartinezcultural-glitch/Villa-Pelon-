# Villa Pelón — Versión 2

RPG 2D web para PC y celulares, inspirado en la vida cotidiana y la identidad de San Patricio del Chañar, Neuquén.

## Jugar
El juego está diseñado para publicarse con GitHub Pages y abrirse desde un enlace, sin instalación.

## V2 — Primer concepto de mundo vivo
- Exploración 2D
- Movimiento del jugador
- Controles PC y táctiles
- NPC y diálogos
- Primera misión y pista educativa
- Dinero, energía e inventario
- Reloj y ciclo día/noche
- Clima cambiante
- Tránsito con autos, camionetas, tractor y camión
- Animales del entorno rural
- Comercios y actividades rurales iniciales
- Guardado local

## Regla del proyecto
Esta rama se identifica exclusivamente como **Versión 2**. No se utilizarán etiquetas V28, V29, V30, V31 ni numeraciones provenientes de otros proyectos.

La prioridad de V2 es demostrar el concepto inicial de **mundo vivo**: el pueblo debe continuar funcionando mientras el jugador recorre el mapa. Los hechos históricos reales deberán incorporar fuentes verificables; la ficción del juego se mantendrá diferenciada de la historia documentada.
