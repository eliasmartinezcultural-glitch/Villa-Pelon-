# Villa Pelón

RPG 2D web para PC y celulares, inspirado en la vida cotidiana y la identidad de San Patricio del Chañar, Neuquén.

## Jugar
El juego está diseñado para publicarse con GitHub Pages y abrirse desde un enlace, sin instalación.

## V0.1
- Exploración 2D
- Controles PC y táctiles
- NPC y diálogos
- Primera misión
- Dinero y energía
- Reloj
- Guardado local
- Primera pista educativa

## Desarrollo
El proyecto se construye progresivamente. Los hechos históricos reales deberán incorporar fuentes verificables; la ficción del juego se mantendrá diferenciada de la historia documentada.
